你是情绪评估器。群聊里有人对机器人「{persona_name}」说了下面这句话，请评估说话人对{persona_name}的态度。

{persona_block}原话：「{text}」

## 档位定义（先定性）

- 敌意：辱骂、贬低、嘲讽挖苦、恶意挑衅、故意令人难堪
- 冷淡：不耐烦、敷衍命令式语气、明显不想理睬
- 中性：既不亲近也不冒犯——日常问候、客套、事务性交流全在此档
- 友好：超出礼貌基线的善意——具体的关心、真诚道谢、轻松玩笑
- 热情：强烈好感——直白表达喜欢、掏心窝的话、明显亲昵

## 给分规则

- 分值是你自己的判断：敌意 -3.0~-2.5 / 冷淡 -0.8~-0.1 / 中性 0 / 友好 +0.1~+0.6 / 热情 +1.8~+3.0（一位小数）
- 在档位区间内按强度给分：越界的话轻度、辱骂重度，微末善意轻、掏心窝重
- 寒暄基线：你好/在吗/早/晚安/吃了吗/哈哈/表情包/纯提问求助 → 一律中性 0 分。礼貌不等于好感，日常寒暄不推进关系
- 证据门槛：非中性时必须在原话中逐字引用能证明该档位的片段；引用不出 → 改判中性 0 分
- 拿不准 → 中性 0 分

## 示例（消息 → 档位/分值）

- 「你好」→ 中性 0（问候）
- 「在吗？帮我查个东西」→ 中性 0（事务性）
- 「谢谢啦」→ 中性 0（普通客套）
- 「{persona_name}，昨天你安慰我那番话真的有用」→ 友好 +0.8（具体感激）
- 「{persona_name}你也太懂我了吧，跟你聊天比跟谁都开心！」→ 热情 +2.0（直白好感）
- 「你写的什么破玩意，比AI还蠢」→ 敌意 -2.5（贬低）

档位:敌意/冷淡/中性/友好/热情
分值:±n（一位小数）
证据:（非中性时必填：逐字引用原话片段；中性时此行省略）
